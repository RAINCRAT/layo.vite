# ==================== 工单模板 ====================
# 说明：
# 1. 本文件为模板，不会计入工单列表（tickets.data.js 已排除 example.md）。
# 2. 每个工单一个 .md，放入本目录（assets/tickets/），列表页自动遍历 frontmatter 生成，无需改代码。
# 3. 文件名建议格式：渠道-日期-序号.md（如 AD-260805-01.md），文件名即路由。
# 4. 复制本文件并修改参数即可新建工单；正文结构参考 assets/tickets/AD-260805-01.md
#    （::: info 提示块 + # 初步诊断 / # 服务记录 大节 + 服务详情表格）。

# ---------- 必填参数 ----------
id: TK-000000-00 # 工单号（唯一标识，建议格式：渠道缩写-日期-序号，如 TK-260805-01）
title: 工单标题 # 工单标题（列表与详情页展示）
status: 待处理 # 状态，可选：待处理 / 处理中 / 已完成 / 已关闭（已完成/已关闭为终态，时间轴最新一项不高亮）
priority: 中优先级 # 优先级，可选：高优先级 / 中优先级 / 低优先级
reporter: 来源 # 来源
createdAt: 2026-08-11 15:22 # 创建时间，格式：YYYY-MM-DD HH:mm

# ---------- 自定义字段 ----------
channel: 直营 # 渠道：自定义字段，任意文本（示例：直营 / 经销商 / 电商 / 官网 / 电话 / 邮件 / 微信…，可按需填写）

# ---------- 固定值（请保留） ----------
sidebar: false # 隐藏左侧菜单栏
aside: false # 隐藏右侧目录

# ---------- 更新记录时间轴 ----------
# updates：工单更新记录，按时间倒序（最新在前）。详情页以时间线展示（首条即最新状态）。
# text 支持行内 Markdown，全部语法用法见下方 updates 示例（复制后按需修改）：
#   - **加粗** / *斜体* / `行内代码` / [链接](https://example.com)
#   - 彩色强调：[[色:文字]]，色名须完全遵循 ak-ui 官方调色板（--ak-color-*，共 14 色）：
#     white / black / low / basic / primary / secondary / advanced / accent /
#     blue / yellow / dark-blue / light-blue / gray / dark（如 [[accent:紧急]]、[[primary:待办]]）
#     强调块（描边+底色）与文字颜色均随色变；内部可内嵌行内语法（**加粗**、*斜体* 按默认色，
#     `代码` 随强调色）或再嵌 [[色:文字]] 嵌套强调（嵌套强调仅文字随色变、不再套块，示例见下方 updates）
#   - 色块悬停：||文字||（默认纯色块遮字，鼠标悬停才显示文字，与全站语法一致，见 theme/ak-inline.js）
# 注意：文本含反引号 `、冒号、引号、方括号、竖线等特殊字符时，必须用单引号包裹
#       （如 text: '`中通快递`工单完结，状态 [[basic:已完成]]'），单引号内的单引号需双写转义（''）。
updates:
  - time: 2026-08-11 17:00
    text: "彩色强调内嵌语法：[[primary:**加粗**、*斜体* 与 [[accent:行内代码]] 混排]]——块随色变，嵌套强调仅文字随色变，粗体/斜体按各自默认色"
  - time: 2026-08-11 16:40
    text: "最新更新内容，支持 **加粗**、*斜体*、`行内代码` 与 [链接](https://example.com)"
  - time: 2026-08-11 15:30
    text: "彩色强调（官方色名）：[[accent:红]]、[[advanced:橙]]、[[yellow:黄]]、[[basic:绿]]、[[light-blue:青]]、[[primary:蓝]]、[[secondary:紫]]、[[low:灰]]"
  - time: 2026-08-11 15:22
    text: "工单创建，含色块悬停：||鼠标悬停才能看到的秘密文字||"
